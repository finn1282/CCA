Part 2 · Layered architecture (adapted from the assignment's Figure 4)

From field data to an explained decision

1Data sources
Sentinel-2 imagery · drone RGB/multispectral · IoT soil sensors (LoRaWAN) · bunch photos · SAP ERP · MSPO standard
Multiscale evidence: satellite covers every block, drones resolve crowns, sensors read continuously.
2Ingestion & big data
IoT Hub + Device Provisioning · Event Grid (MQTT) · Event Hubs · Data Lake Storage Gen2 · Planetary Computer (STAC)
Device identity and two-way messaging; streaming telemetry; one lake for imagery and readings.
3Cognitive services
Vision models (ripeness, crown detection) · NDVI anomaly detection · fertiliser recommender · MSPO knowledge base & reasoning · NLP explanations (Azure OpenAI)
CNNs read images; anomaly detection catches a disease that is invisible early; rules + knowledge base suit a regulated decision. The language model only rewrites explanations; it never decides.
4Cloud & deployment
Azure Machine Learning: training, registry, managed endpoints, monitoring · Azure IoT Operations at the estate edge
Versioned, monitored models; the edge keeps working offline (validated after up to 45 days).
5Application
Manager dashboard · mandore mobile app · agronomist review queue · MSPO audit pack · ERP work orders
Each user gets the decision they own, with its reason.

Cross-cutting

  • PDPA residency split
  • Entra ID & Key Vault
  • Grad-CAM + Responsible AI (tabular)
  • Confidential-ledger evidence log
  • Human review of every action
Built on Microsoft Azure, our chosen platform Malaysia West: personal data (Event Grid MQTT, Event Hubs, Storage, App Service) Southeast Asia: Azure ML, IoT Hub/DPS, Ledger, OpenAI; non-personal or hashed data only

Short · 0–6 months

Pilot

  • 1 estate, 2–3 blocks incl. one with BSR history
  • F1, F4, F5 on a rule-based baseline; F3 trial
  • Human approves every action; ERP read-only
  • Success: agronomist agreement ≥80 %; audit pack accepted
Medium · 6–18 months

Scale & integrate

  • All estates in one region
  • Baseline replaced by estate-trained models; F2 live; drift monitoring
  • SAP write-back; ledger anchoring
  • Success: shorter rounds, fewer over-ripe bunches
Long · 18–36 months

Optimise & extend

  • Group-wide + smallholder co-operatives
  • Yield forecasting; multispectral BSR; multilingual audit narrative
  • MSPO GHG export; EUDR geolocation package
  • Success: measurable OER gain; zero record findings
