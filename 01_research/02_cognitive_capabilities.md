# 02 — Cognitive Capabilities per Outcome (short v1)

> Owner: Research. Wave 1 = short first version; deeper literature review can be requested via `REQUESTS.md`. Keys → `sources.md`. Accuracies are **not directly comparable** (different datasets, classes, metrics).

| Outcome | Capability (cognitive function) | State of the art — evidence | Typical reported performance | Implication for our design |
|---|---|---|---|---|
| **O1** Ripe-FFB harvest window | Computer vision — image classification / object detection (pattern recognition) | Malaysian study (MMU) compared MobileNetV2-SSD, EfficientDet-Lite0–2 and YOLOv5n/s/m on 4 ripeness classes (304 images, ground-level, Colab K80) [MANSOUR2022]; Malaysian outdoor dataset with on-tree + ground images, 5 classes [OMAR2024]; ripeness changes oil content (>40 % at full maturity) and quality between 19–24 weeks after anthesis [RAMLI2026] | Best: **YOLOv5m mAP@0.5:0.95 = 0.842** [MANSOUR2022] | Transfer-learned classifier (EfficientNet/MobileNet or YOLOv8-cls) on D1, test on Malaysian D2. Harvest window = classifier output per block + ripening-age rule (bunches checked again in N days) — label the scheduling part as rule-based/simulated |
| **O2** Early Ganoderma detection | Remote-sensing ML: spectral/texture pattern recognition, anomaly detection, deep CNNs | UAV + Pleiades multispectral with convolutional SVM, UPM co-author [AHMADI2023]; UAV **hyperspectral** + PCA, SVM vs fine-tuned ResNet50 (MMU, TENCON 2025) [KWANG2025]; hyperspectral/AISA and QuickBird approaches reviewed — early detection still hard, malnutrition confusion [KHOO2023] | Early-stage UAV multispectral ≈ **64–68 %** overall [AHMADI2023]; UAV hyperspectral ResNet50 **84 % overall, 74 % sensitivity (early infected), 86 % specificity** [KWANG2025] | Be honest: early detection accuracy is moderate even in research. Position the system as **screening + prioritisation** (rank palms for ground-truth/GSM test), not diagnosis. Our demo model: YOLO on D4 UAV RGB (field-confirmed labels) + Sentinel-2 NDVI anomaly |
| **O3** Fertiliser optimisation | Supervised ML on sensor/spectral features + knowledge-based reasoning (agronomic rules) + explainable AI | UPM + Sime Darby Plantation Research: Landsat-8 + RF/SVM/ANN classify plot-level leaf N, P, K, Mg, Ca under variable-rate fertiliser plots in Malaysia [KOK2021]; MSPO 2022 expects documented fertilising & soil-fertility SOPs and GHG awareness (N₂O from fertiliser) [MPOCC-P21] | Best mean overall accuracy **N 79.7 ± 4.3 %, K 76.6 ± 4.1 %**; P, Mg, Ca not reliably classified [KOK2021] | Hybrid: rules from agronomy (pH bands [KANANG2026], drainage [AAR-SOIL], water deficit [CARR2011]) + ML on simulated sensor data + SHAP/decision-path explanations → "fertilise / lime / irrigate / skip" with reason. Satellite nutrient maps are a **future extension** |
| **O4** Yield & MSPO | Data fusion, knowledge representation (MSPO criteria as rules/ontology), reasoning, NLP over audit records (future) | MSPO traceability, records and GHG criteria [MPOCC-P21]; EUDR geolocation gaps [MSPO-EFI2025] | n/a | Auto-generate an MSPO evidence log (fertiliser actions + reasons, disease screening, block geolocation) — supports Part 3 novelty (explainable, audit-ready AI) |

## Notes for Software / Report
- Mention **explainability** explicitly per model: Grad-CAM heatmaps on ripeness/Ganoderma images; feature-attribution text for fertiliser advice.
- Accuracy targets for our own models should be reported on a **held-out Malaysian or geographically disjoint test set** (D2 for ripeness; D4's provided spatial split for Ganoderma).
